# 飞牛文档目录怎么放

NAS 上单独文件夹（与代码仓、聊天数据分开）：

```text
/vol1/1000/wechat-ingest-文档/
  README.md                 本说明
  脱密/                     可给别人、可进 GitHub
    项目介绍.md             与仓库 README 同步
    开发文档.md             DEVELOPMENT.md
    飞牛部署.md             DEPLOY-FNOS.md
    全能签注入.md
    TrollFools注入.md
    部署脚本/               deploy/ + console 示例 compose
  不脱密/                   仅自己用，不要公开
    开发手册.md             DEV-INTERNAL.md
```

GitHub 只同步「脱密」和仓库根 README。
